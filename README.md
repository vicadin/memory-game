# Memory Game

A classic card-matching memory game built with Vanilla JavaScript, modern CSS, and HTML. Test your visual memory by finding all matching pairs of cards in the fewest moves possible.

## How to Play

1. Click on any card to flip it face up.
2. Click on a second card to reveal its image.
3. If both cards match, they remain open until the end of the game.
4. If they do not match, both cards flip back down after a brief delay.
5. The game is won when all 8 pairs have been successfully uncovered.

## Tech Stack

- **JavaScript**: Vanilla JS
- **Styles**: Modern CSS
- **Bundler**: Vite

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm

### Installation

Clone the repository and install dependencies:

```bash
npm install
```

### Development Server

Run the local development server:

```bash
npm run dev
```

### Production Build

Create an optimized production build:

```bash
npm run build
```
